# TestLens

> Discover, run and track automated tests across **C#, Vue and Angular** projects — with a beautiful self-contained HTML report, full run history, trends and highlights.

This is the npm distribution of TestLens. It requires the free, cross-platform [.NET 8 runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (or newer) to be installed.

```bash
npm install -g testlens

testlens ./my-repos           # scan, run tests, record a snapshot
open my-repos/.testlens/index.html
```

Prefer the .NET ecosystem? Install it as a dotnet tool instead:

```bash
dotnet tool install --global TestLens
```

Full documentation, screenshots and source: **https://github.com/thedigitaljedi86/TestLens**
